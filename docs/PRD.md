# 할 일 관리 앱 PRD

## 1. Why - 목적
- 일일 할 일과 장기 목표를 하나의 구조로 연결
- 할 일 → 주간 계획 → 1년 목표 계층으로 실행과 목표를 정렬
- 상태(todo/doing/done) 기반 진행 상황 가시화
- 주간 진행률 자동 계산으로 수동 집계 제거

## 2. who - 타깃 사용자
- GitHub 계정이 있는 사용자 (GitHub로 로그인)
- 일일 업무를 주간, 연간 목표와 연결해 관리하려는 개인 사용자
- 칸반(상태 보드) 방식으로 할 일을 관리하는 사용자
- 주 단위로 진행률을 점검하는 사용자

## 3. USer flow
1. 1년 목표 생성
2. 주간 계획 생성 → 1년 목표에 연결
3. 일일 할 일 생성 → 주간 계획에 연결
4. 보드 화면에서 할 일 확인 (todo / doing / done 컬럼)
5. 드래그 앤 드롭으로 할 일 상태 변경
6. 상태 변경 시 주간 진행률 자동 갱신
7. 주간 계획 화면에서 진행률 확인
8. 1년 목표 화면에서 연결된 주간 계획 목록 확인
9. 할 일 / 주간 계획 / 1년 목표 수정 및 삭제

## 4. 기능 요구 사항

### P0-  핵심 기능

**4-1. 할 일 CRUD**
- 생성: 제목(필수), 날짜(필수), 상태(기본값 todo), 연결 주간 계획(선택)
- 조회: 일일 단위 목록
- 수정: 제목, 날짜, 상태, 연결 주간 계획, 메모 변경
- 삭제: 삭제 확인 후 삭제, 연결된 주간 진행률 즉시 재계산

**4-2. 상태 관리**
- 상태 값: todo / doing / done
- 상태 전환: 모든 상태 간 자유 이동 허용
- 상태 변경 시점 기록 (updated_at)

**4-3. 드래그 앤 드롭 상태 변경**
- 보드 컬럼: todo / doing / done
- 카드를 다른 컬럼으로 드롭 → 상태 변경 저장
- 같은 컬럼 내 드롭 → 상태 변경 없음
- 저장 실패 시 원래 컬럼으로 복귀 + 오류 표시

**4-4. 기간 구조**
- 일일: 할 일 (날짜 단위)
- 주간: 주간 계획 (시작일~종료일, 7일 단위)
- 1년: 1년 목표 (연도 단위)
- 각 기간 항목 CRUD 지원
- 할 일, 주간 계획, 1년 목표 모두 메모(선택, 최대 2000자, 여러 줄)를 적을 수 있음

**4-5. 구조 연결**
- 할 일 → 주간 계획: N:1
- 주간 계획 → 1년 목표: N:1
- 연결은 선택 사항 (미연결 상태 허용)
- 상위 항목 삭제 시 하위 항목은 유지, 연결만 해제

**4-6. 주간 진행률 자동 반영**
- 계산식: 연결된 할 일 중 done 개수 / 연결된 할 일 전체 개수 × 100
- 갱신 시점: 할 일 생성, 삭제, 상태 변경, 연결 변경 시
- 연결된 할 일 0개 → 진행률 0% 표시
- 주간 계획 화면에 진행률 표시

**4-7. 데이터 모델**
- Task: id, user_id, title, date, status, weekly_plan_id, memo, created_at, updated_at
- WeeklyPlan: id, user_id, title, start_date, end_date, yearly_goal_id, memo, progress
- YearlyGoal: id, user_id, title, year, memo
- User: id, github_id, username, avatar_url, created_at, updated_at
- Session: id, token_hash, user_id, expires_at

**4-8. GitHub 로그인** (요구 문서: docs/LOGIN.md, 설정: docs/GITHUB_OAUTH.md)
- GitHub OAuth로 로그인: `/auth/github`(시작), `/auth/github/callback`(완료)
- 로그인하면 GitHub username, avatar_url을 저장하고 상단에 표시
- 로그인하지 않으면 화면은 /login으로 리다이렉트, API는 401
- 할 일·주간 계획·1년 목표는 본인 것만 조회/수정/삭제 가능 (다른 사람 항목은 없는 것처럼 404, 연결 시도는 400)
- 주간 계획 "한 주에 하나" 규칙은 사용자별로 적용
- 로그아웃하면 세션을 DB에서 완전히 삭제
- 기존 데이터는 마이그레이션(`npm run migrate:user-id`)으로 특정 사용자에게 할당

### P1- 추가 기능
- 1년 목표 진행률: 연결된 주간 계획 진행률 평균으로 자동 계산
- 보드 필터: 날짜, 주간 계획 기준 필터링
- 미연결 할 일 목록 별도 표시
- 컬럼 내 카드 순서 드래그 정렬
